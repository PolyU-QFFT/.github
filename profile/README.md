## 组织说明

**介绍**：这是PolyU-QFFT项目的非官方组织，本组织私库包含本专业前辈整理的各类课程相关信息，请勿外传，请勿商用，请勿为本组织成员身份付费

**加入**：联系akiudion@gmail.com，邮件标题需要含QFFT四字，正文包含你的github用户名、入学年份。可以选择2种方式之一验证你的身份：1.邮件中附带你的学生卡照片或本专业录取通知书；2.不愿意发照片的同学可以进行一轮问答。通过后会邀请进入组织。

**贡献**：可以在私库中提PR，内容包括教学内容、个人心得、笔记，也可以是找工情况、面试心得或内推等等

**鸣谢**：`ryonzhan-zzz`学长是该项目牵头人，作为第一届小白鼠为25fall及之后的同学们提供了非常多的宝贵建议
